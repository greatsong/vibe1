  • 전국 고령화 지도 앱 — 시군구 255곳의 65세 이상 비율을 색으로 칠한 단계구분도입니다
  • 내 앱 주소 — 내가정한이름.streamlit.app 형태의 주소가 생기고, 오늘 남은 시간에 계속 씁니다

순서는 빈 앱을 먼저 배포하고, 그 위에 지도를 얹는 것입니다. 코드를 다 만든 다음 마지막에 배포하면 어디서 어긋났는지 찾기 어렵습니다. 계정 연결이 되는지부터 확인하고 넘어갑니다.

1. 오늘 쓸 데이터

내려받거나 정리할 것은 없습니다. 아래 두 주소를 프롬프트에 적으면 앱이 인터넷에서 직접 읽습니다.

📦 파일 두 개
  • 인구 — population_yearly.csv.gz
    행정안전부 주민등록 인구. 2015~2026년 · 전국 읍·면·동 4만 2천여 행 · 1세 단위 남녀 인구. 압축 파일이지만 pandas가 그대로 읽습니다
  • 경계 — sigungu_kr.geojson
    전국 시군구 255개의 모양. 지역마다 속성은 코드·시군구·시도 셋입니다
  • 인구표에는 지역 모양이 없고, 경계 파일에는 인구 숫자가 없습니다. 지도 하나를 그리려면 둘을 붙여야 합니다
  • 붙이는 기준은 행정동 코드입니다. 인구표 코드의 앞 5자리가 경계 파일의 코드와 같습니다
⚠️ 이름으로 붙이면 어긋납니다
  • 남구는 부산·대구·인천·울산·광주에 다 있습니다. 중구·동구·서구도 마찬가지입니다
  • 이름으로 짝지으면 여러 곳이 한 덩어리가 되거나 엉뚱한 지역이 칠해집니다. 반드시 코드로 짝지어야 합니다
  • 코드는 앞자리가 0인 값이 있어서 숫자로 읽으면 자릿수가 어긋납니다. 글자로 읽어야 합니다
  • 이 두 가지를 프롬프트에 미리 적어 둡니다. AI가 알아서 피해 가지 않는 부분입니다

앱 하나에 저장소 하나입니다. 오늘 만드는 앱은 전부 이 저장소에서 app.py 내용만 바꿔 가며 이어집니다.

    Repository name에 my-vibe-app · Public 선택 · Add a README file 체크 → 초록 Create repository

    Add file → Create new file → 파일명 requirements.txt → 아래 두 줄 붙여넣기 → 맨 아래 초록 Commit changes → 팝업에서 다시 Commit changes
  4. app.py 만들기
    다시 Add file → Create new file → 파일명 app.py → 아래 네 줄 붙여넣기 → Commit changes

4. 지도 앱 주문하기

1절에서 확인한 것을 그대로 주문서에 옮깁니다. 열 이름 · 코드 자릿수 · 짝짓는 방법을 적어 두면 AI가 필드 이름을 지어내지 않습니다.

① 샘플 프롬프트
전국 고령화 지도를 보여 주는 스트림릿 앱 하나(app.py)를 만들어 줘. 스트림릿 클라우드에 올릴 거야.
시군구별 65세 이상 인구 비율을 색으로 칠한 단계구분도야.

■ 인구 데이터
- 주소: https://raw.githubusercontent.com/greatsong/modudata/main/data/population_yearly.csv.gz
- 2015~2026년 전국 읍·면·동 인구야. 가장 최신 연도로 그려 줘.
- 열은 연도 · 시도 · 시군구 · 동 · 코드, 그리고 나이별 인구 열이야.
- 나이별 열 이름은 '계_0세' · '남_0세' · '여_0세' 형식으로 나이마다 셋씩 있고 '계_100세 이상'까지 이어져.
  '계_'가 남녀를 합친 값이야.
- '코드'는 행정동 코드 열 자리인데 앞자리가 0인 값이 있어. 반드시 글자로 읽어. 숫자로 읽으면 앞의 0이 날아가.
- 인구는 읍·면·동 단위야. '코드' 앞 5자리가 시군구를 가리켜.

■ 지도 경계 데이터
- 주소: https://raw.githubusercontent.com/greatsong/modudata/main/data/boundaries/sigungu_kr.geojson
- 전국 시군구 255개의 경계가 들어 있는 GeoJSON이야.
- 지역마다 속성이 세 개야: '코드'(5자리) · '시군구' · '시도'.

■ 지도
- 지역은 이름이 아니라 '코드'로 맞춰 줘. 이름으로 맞추면 '남구'처럼 여러 시도에 같은 이름이 있어서 어긋나.
- 배경 지도 타일 없이 경계선만 보이게.
- 색은 이어지는 그라데이션 말고 5단계로 끊어 줘. 구간 경계값은 19% · 23% · 28% · 38%.
  전국 시군구를 다섯 덩어리로 나눈 실제 값이야. 낮은 쪽은 옅게, 높은 쪽은 진하게.
- 범례에 각 단계의 비율 구간이 글자로 보이게. 예: '19% 미만', '38% 이상'.
- 마우스를 올리면 시군구 이름 · 시도 · 고령화율(%)이 보이게.
- 지도 아래에 고령화율 높은 곳 10개와 낮은 곳 10개를 표 두 개로 나란히 보여 줘.

■ 규칙
- 한국어 라벨, 초보자용 한국어 주석.
- 저장소에 requirements.txt를 이미 만들어 뒀어. plotly와 requests가 들어 있어.
  더 필요한 게 있으면 이름만 알려 줘. 스트림릿·판다스·넘파이는 기본 설치라 빼고.
- app.py 전체 코드를 한 번에 줘.

5. 돌아온 코드

완성된 코드 한 덩어리가 옵니다. 내 것과 글자까지 같지 않아도 됩니다. 이런 모습이면 성공입니다.

② AI가 준 코드 예시
import re
import requests
import pandas as pd
import streamlit as st
import plotly.express as px

st.set_page_config(page_title="전국 고령화 지도", layout="wide")
st.title("🗺️ 전국 고령화 지도")
st.caption("시군구별 65세 이상 인구 비율 (행정안전부 주민등록 인구)")

POP_URL = "https://raw.githubusercontent.com/greatsong/modudata/main/data/population_yearly.csv.gz"
GEO_URL = "https://raw.githubusercontent.com/greatsong/modudata/main/data/boundaries/sigungu_kr.geojson"


@st.cache_data(show_spinner="인구 데이터를 불러오는 중입니다...")
def load_population():
    # '코드' 열은 앞자리 0이 사라지지 않게 글자로 읽습니다
    return pd.read_csv(POP_URL, dtype={"코드": str})


@st.cache_data(show_spinner="지도 경계를 불러오는 중입니다...")
def load_geojson():
    return requests.get(GEO_URL, timeout=30).json()


df = load_population()
geojson = load_geojson()

# 1. 가장 최신 연도만 사용
latest_year = int(df["연도"].max())
df = df[df["연도"] == latest_year].copy()

# 2. '계_'로 시작하는 나이 열만 (남_·여_ 열까지 더하면 두 배가 됩니다)
total_cols = [c for c in df.columns if c.startswith("계_")]


def age_of(col):
    m = re.match(r"계_(\d+)세", col)
    return int(m.group(1)) if m else None


# 3. 그중 65세 이상 열만 ('계_65세' ~ '계_100세 이상')
elderly_cols = [c for c in total_cols if age_of(c) is not None and age_of(c) >= 65]

# 4. 동 단위로 전체 인구·고령 인구 계산
df["전체인구"] = df[total_cols].sum(axis=1)
df["고령인구"] = df[elderly_cols].sum(axis=1)

# 5. '코드' 앞 5자리 = 시군구 코드 → 시군구별로 묶어 비율 계산
df["시군구코드"] = df["코드"].str[:5]
grouped = df.groupby("시군구코드")[["전체인구", "고령인구"]].sum().reset_index()
grouped["고령화율"] = (grouped["고령인구"] / grouped["전체인구"] * 100).round(2)

# 경계 파일에서 코드 → 시군구·시도 이름 짝 만들기
names = pd.DataFrame([
    {
        "시군구코드": str(f["properties"]["코드"]),
        "시군구": f["properties"]["시군구"],
        "시도": f["properties"]["시도"],
    }
    for f in geojson["features"]
])
merged = grouped.merge(names, on="시군구코드", how="left")

# 6. 5단계 색 구간 (전국 시군구를 다섯 덩어리로 나눈 실제 경계값)
BINS = [0, 19, 23, 28, 38, 100]
LABELS = ["19% 미만", "19~23%", "23~28%", "28~38%", "38% 이상"]
COLORS = {
    "19% 미만": "#fee6ce",
    "19~23%": "#fdc086",
    "23~28%": "#f79646",
    "28~38%": "#e8590c",
    "38% 이상": "#a63603",
}
merged["단계"] = pd.cut(merged["고령화율"], bins=BINS, labels=LABELS, right=False)

# 7. 단계구분도 그리기 (배경 지도 타일 없이 경계만)
fig = px.choropleth(
    merged,
    geojson=geojson,
    locations="시군구코드",
    featureidkey="properties.코드",
    color="단계",
    category_orders={"단계": LABELS},
    color_discrete_map=COLORS,
    hover_name="시군구",
    hover_data={"고령화율": True, "시도": True, "시군구코드": False, "단계": False},
    labels={"고령화율": "65세 이상 비율(%)"},
)
fig.update_geos(fitbounds="locations", visible=False)
fig.update_layout(
    margin=dict(l=0, r=0, t=10, b=0),
    height=700,
    legend_title_text=f"65세 이상 비율 ({latest_year}년)",
)

st.plotly_chart(fig, use_container_width=True)

# 8. 지도 아래 순위 표 두 개
c1, c2 = st.columns(2)
cols = ["시도", "시군구", "고령화율"]
with c1:
    st.subheader("🔴 고령화율 높은 곳 10")
    st.dataframe(merged.nlargest(10, "고령화율")[cols].reset_index(drop=True))
with c2:
    st.subheader("🟢 고령화율 낮은 곳 10")
    st.dataframe(merged.nsmallest(10, "고령화율")[cols].reset_index(drop=True))

  • 경상북도·전라남도 내륙이 가장 진하고, 수도권 신도시와 세종이 가장 옅게 나옵니다
  • 아래 표에서 확인할 값 — 가장 높은 곳 의성군 50.1%, 가장 낮은 곳 화성시동탄구 7.1% (2026년 기준). 소수 자릿수는 AI가 정하기 나름이라 50.11로 나와도 맞습니다
  • 지도가 회색 한 덩어리이거나 텅 비었다면 이름으로 짝지은 경우입니다. “지역은 이름이 아니라 코드로 맞춰 줘”를 다시 보내세요

  연도가 바뀌어도 색 구간 경계값(19 · 23 · 28 · 38%)은 그대로여야 해마다 색을 비교할 수 있어.
- 지도 위에 지표 카드 세 장을 나란히: 전국 고령화율, 가장 높은 시군구, 가장 낮은 시군구.
- 시도를 고르면 그 시도만 확대해 보여 주는 드롭다운을 달아 줘. '전국'도 고를 수 있게.
- 65세 이상 말고 0~14세 비율(유소년)도 볼 수 있게 지표 선택 상자를 달아 줘.
  유소년은 비율이 훨씬 낮아서 같은 구간을 쓰면 지도가 한 색이 돼. 색 구간을 그 지표에 맞게 다시 잡아 줘.
🧯 시간이 부족하거나 프롬프트가 어긋났다면 — 완성 코드 복붙

아래를 app.py에 통째로 붙여넣고 커밋하면 위 화면이 그대로 나옵니다. 먼저 진도를 맞추고, 프롬프트는 쉬는 시간에 다시 돌려 보셔도 됩니다.

app.py 전체 (그대로 복사)
import re
import requests
import pandas as pd
import streamlit as st
import plotly.express as px

st.set_page_config(page_title="전국 고령화 지도", layout="wide")
st.title("🗺️ 전국 고령화 지도")
st.caption("시군구별 65세 이상 인구 비율 (행정안전부 주민등록 인구)")

POP_URL = "https://raw.githubusercontent.com/greatsong/modudata/main/data/population_yearly.csv.gz"
GEO_URL = "https://raw.githubusercontent.com/greatsong/modudata/main/data/boundaries/sigungu_kr.geojson"


@st.cache_data(show_spinner="인구 데이터를 불러오는 중입니다...")
def load_population():
    return pd.read_csv(POP_URL, dtype={"코드": str})


@st.cache_data(show_spinner="지도 경계를 불러오는 중입니다...")
def load_geojson():
    return requests.get(GEO_URL, timeout=30).json()


df = load_population()
geojson = load_geojson()

latest_year = int(df["연도"].max())
df = df[df["연도"] == latest_year].copy()

total_cols = [c for c in df.columns if c.startswith("계_")]


def age_of(col):
    m = re.match(r"계_(\d+)세", col)
    return int(m.group(1)) if m else None


elderly_cols = [c for c in total_cols if age_of(c) is not None and age_of(c) >= 65]

df["전체인구"] = df[total_cols].sum(axis=1)
df["고령인구"] = df[elderly_cols].sum(axis=1)

df["시군구코드"] = df["코드"].str[:5]
grouped = df.groupby("시군구코드")[["전체인구", "고령인구"]].sum().reset_index()
grouped["고령화율"] = (grouped["고령인구"] / grouped["전체인구"] * 100).round(2)

names = pd.DataFrame([
    {
        "시군구코드": str(f["properties"]["코드"]),
        "시군구": f["properties"]["시군구"],
        "시도": f["properties"]["시도"],
    }
    for f in geojson["features"]
])
merged = grouped.merge(names, on="시군구코드", how="left")

BINS = [0, 19, 23, 28, 38, 100]
LABELS = ["19% 미만", "19~23%", "23~28%", "28~38%", "38% 이상"]
COLORS = {
    "19% 미만": "#fee6ce",
    "19~23%": "#fdc086",
    "23~28%": "#f79646",
    "28~38%": "#e8590c",
    "38% 이상": "#a63603",
}
merged["단계"] = pd.cut(merged["고령화율"], bins=BINS, labels=LABELS, right=False)

fig = px.choropleth(
    merged,
    geojson=geojson,
    locations="시군구코드",
    featureidkey="properties.코드",
    color="단계",
    category_orders={"단계": LABELS},
    color_discrete_map=COLORS,
    hover_name="시군구",
    hover_data={"고령화율": True, "시도": True, "시군구코드": False, "단계": False},
    labels={"고령화율": "65세 이상 비율(%)"},
)
fig.update_geos(fitbounds="locations", visible=False)
fig.update_layout(
    margin=dict(l=0, r=0, t=10, b=0),
    height=700,
    legend_title_text=f"65세 이상 비율 ({latest_year}년)",
)

st.plotly_chart(fig, use_container_width=True)

c1, c2 = st.columns(2)
cols = ["시도", "시군구", "고령화율"]
with c1:
    st.subheader("🔴 고령화율 높은 곳 10")
    st.dataframe(merged.nlargest(10, "고령화율")[cols].reset_index(drop=True))
with c2:
    st.subheader("🟢 고령화율 낮은 곳 10")
    st.dataframe(merged.nsmallest(10, "고령화율")[cols].reset_index(drop=True))
