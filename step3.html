나만의 AI 채팅앱

🎯 이 35분에 만드는 것
  • AI 채팅앱 — 말을 걸면 정해 준 성격대로 답하고, 앞서 나눈 이야기를 기억하는 앱
  • 저장소도 앱 주소도 그대로. STEP 2와 똑같이 app.py 한 파일만 바꿔 올립니다
  • 성격 문장 한 줄을 바꾸면 과목별 도우미가 됩니다

STEP 2에서 KOBIS로 밟은 순서가 있습니다. 주소를 찾고, 키를 금고에 넣고, 요청을 보내고, 응답을 화면에 올렸습니다. 그 순서는 KOBIS 전용이 아니라 어떤 창구에나 그대로 통합니다. 이번에는 처음 보는 창구에 같은 순서를 적용합니다.

새로 나오는 것은 두 가지입니다. 답이 매번 새로 만들어진다는 것과, 대화를 기억하게 만들어야 한다는 것.

1. 데이터 API와 AI API

데이터 API (KOBIS)AI API (Solar)
같은 질문을 두 번늘 같은 답매번 다른 답
답이 오는 곳이미 저장돼 있는 기록요청을 받고 그 자리에서 생성
요금대개 무료 · 하루 호출 수 제한주고받은 글자 양만큼 과금
실패 신호응답 안에 오류 상자(faultInfo)상태코드 401(키 오류) · 429(요청 과다)

다른 점은 이만큼이고, 나머지는 STEP 2와 같습니다. 주소가 있고, 키가 있고, 요청을 보내면 응답이 옵니다.

2. AI 키 준비

  • 오늘 쓰는 AI는 Solar(솔라)입니다. 우리나라 회사 업스테이지의 모델이고 한국어가 강합니다. 모델 이름은 solar-open2
  • 실습용 키는 현장에서 나눠 드립니다. 아래 칸에 붙여넣으면 금고 예시에 자동으로 채워집니다
  • 내 키를 직접 만들려면 업스테이지 콘솔(console.upstage.ai) → 로그인 → API Keys → Create New Key. 카드 등록 없이 3분이면 됩니다
🗝️ 받은 Solar 키 붙여넣기 — 아래 금고 예시에 자동으로 채워집니다
키는 이 화면 안에서만 쓰이고 어디에도 저장·전송되지 않습니다

금고는 줄을 지우지 말고 아래에 한 줄 더 붙입니다. STEP 2의 KOBIS_KEY는 그대로 두세요.

Settings → Secrets (한 줄 추가)
KOBIS_KEY = "STEP 2에서 넣은 키"
SOLAR_API_KEY = "받은 실습용 키"
⚠️ 금고 이름과 코드 이름은 글자까지 같아야 합니다
  • 금고 라벨 · 프롬프트에 적은 이름 · 코드에서 꺼내는 이름, 셋이 한 글자도 다르면 안 됩니다
  • 키 값 자체는 코드에 적지 마세요. GitHub 공개 저장소에 올라간 키는 봇이 몇 분 안에 주워 갑니다
💸 AI 키는 요금과 직결됩니다
  • 유출되면 남이 내 요금으로 씁니다. 의심되면 그 키를 삭제하고 새로 발급하세요. 키는 발급 순간 한 번만 보이니 바로 복사해 금고에 넣습니다
  • 좋은 모델일수록 비쌉니다. 최고급 모델은 저가형의 수십 배입니다. 실습에는 무료·저가 모델로 충분합니다 (Solar 무료 베타 · Gemini flash 계열 · Claude Haiku 계열)
  • 유료로 쓸 때는 콘솔에서 월 사용 한도를 걸어 두세요. 실수해도 한도에서 멈춥니다

3. 대화를 기억한다는 것

채팅앱에서 새로 나오는 부분은 여기 하나입니다. 스트림릿 앱은 메시지가 하나 올 때마다 화면을 처음부터 다시 그립니다. 지금까지 오간 말을 따로 담아 두지 않으면 직전 질문도 남지 않습니다.

  • AI 쪽 창구도 이전 대화를 보관하지 않습니다. 요청할 때마다 지금까지의 대화 전체를 다시 보내야 이어서 답합니다
  • AI에게 미리 주는 성격 문장(시스템 프롬프트)도 그 묶음 맨 앞에 함께 갑니다. 화면에는 띄우지 않습니다
  • 대화가 길어질수록 보내는 양이 늘고 요금도 같이 늡니다. 그래서 뒤에서 대화 지우기 버튼을 붙입니다

4. 프롬프트로 만들기

접속 주소·모델 이름·키 이름을 프롬프트에 정확히 적습니다. 이 셋을 비워 두면 AI가 그럴듯한 값을 지어냅니다.

① 샘플 프롬프트
스트림릿으로 AI 채팅앱 하나(app.py)를 만들어줘. 스트림릿 클라우드에 올릴 거야.

- Solar API(모델 solar-open2, 접속 주소 https://api.upstage.ai/v1)를
  openai 라이브러리로 사용해. 모델 이름은 글자 그대로 쓰고 다른 이름으로 바꾸지 마.
- API 키는 코드에 쓰지 말고, 비밀 금고(secrets)의 SOLAR_API_KEY에서 불러와.
- 답이 빨리 나오도록 추론(생각) 기능은 꺼줘.
- 채팅 입력창으로 메시지를 보내면 AI의 답이 말풍선으로 이어지게 해줘.
- 답은 글자가 실시간으로 흘러나오게 보여줘.
- AI가 이전 대화를 기억하며 이어서 답하게 해줘.
- AI에게 '너는 중고등학생에게 설명하는 친절한 정보 선생님이야.
  어려운 말은 쉬운 말로 바꿔 주고, 반드시 순수 한국어로만 답해'라는 성격을 줘.
  이 성격 문장은 화면에 띄우지 마.
- 요청이 실패하면 빨간 오류 화면을 그대로 보여주지 말고,
  한국어 안내 문구 한 줄을 보여줘.
- 필요한 라이브러리 목록(requirements.txt)도 같이 줘. 버전 숫자 없이 이름만,
  스트림릿·판다스·넘파이는 기본 설치라 빼고. 이 앱은 openai 하나면 돼.
- 초보자용 한국어 주석을 달아. app.py 전체 코드를 한 번에 줘.
  • 아래는 받게 될 코드의 모습 예시입니다. 변수 이름이나 배치가 조금 달라도 대화가 이어지면 됩니다
② AI가 준 코드 예시 (app.py)
import streamlit as st
from openai import OpenAI

# 페이지 기본 설정
st.set_page_config(page_title="AI 정보 선생님", page_icon="🤖")
st.title("🤖 AI 정보 선생님")

# 비밀 금고(secrets)에서 API 키를 꺼내 접속 준비
client = OpenAI(
    api_key=st.secrets["SOLAR_API_KEY"],
    base_url="https://api.upstage.ai/v1",
)

# AI의 성격 (화면에는 띄우지 않고 요청에만 함께 보낸다)
SYSTEM_PROMPT = (
    "너는 중고등학생에게 설명하는 친절한 정보 선생님이야. "
    "어려운 말은 쉬운 말로 바꿔 주고, 반드시 순수 한국어로만 답해"
)

# 대화 기록이 없으면 처음 한 번만 만들어 둔다
if "messages" not in st.session_state:
    st.session_state.messages = [{"role": "system", "content": SYSTEM_PROMPT}]

# 지금까지의 대화를 말풍선으로 다시 그리기 (성격 문장은 숨김)
for msg in st.session_state.messages:
    if msg["role"] != "system":
        with st.chat_message(msg["role"]):
            st.markdown(msg["content"])

# 채팅 입력창
user_input = st.chat_input("궁금한 것을 물어보세요!")

if user_input:
    # 보낸 말을 기록에 넣고 화면에도 그리기
    st.session_state.messages.append({"role": "user", "content": user_input})
    with st.chat_message("user"):
        st.markdown(user_input)

    # AI 답 받아오기 (실패하면 빨간 오류 화면 대신 안내 문구)
    with st.chat_message("assistant"):
        try:
            stream = client.chat.completions.create(
                model="solar-open2",                 # 모델 이름은 그대로 유지
                messages=st.session_state.messages,  # 대화 전체를 함께 보내 기억 유지
                reasoning_effort="none",             # 추론 끄기 -> 바로 답변 시작
                stream=True,                         # 글자가 실시간으로 흐르게
            )
            answer = st.write_stream(
                chunk.choices[0].delta.content or ""
                for chunk in stream if chunk.choices
            )
            # AI 답도 기록에 저장 (다음 질문에 이어서 사용)
            st.session_state.messages.append({"role": "assistant", "content": answer})
        except Exception:
            st.error("응답을 받지 못했습니다. 잠시 후 다시 보내 주세요.")

  2. 파일 교체

  3. requirements.txt 확인
    같은 저장소의 requirements.txt에 openai 줄이 있는지 확인. 없으면 연필로 한 줄 추가
  4. 커밋

✔️ 이렇게 되면 성공
  • 인사를 건네서 AI가 한국어로 답하면 성공입니다. 글자가 왼쪽부터 흘러나오면 스트리밍까지 성공
  • 이름을 알려 준 다음 "내 이름 뭐라고 했지?"라고 물어보세요. 기억하고 답하면 대화 기록까지 성공입니다
  • 답이 한참 안 오면 ①의 추론(생각) 기능은 꺼줘 줄이 빠졌는지 확인하고 다시 주문하세요. 추론이 켜지면 수십 초를 생각부터 합니다
  • 기다리는 동안 전송을 연타하지 마세요. 요청 과다(429)로 이어집니다
  • 키 오류(401)가 뜨면 금고 라벨 SOLAR_API_KEY와 키 값에 따옴표·공백이 섞였는지 확인하세요
  • 모델 이름 오류가 뜨면 AI에게 "업스테이지의 현재 채팅 모델 이름을 알려줘"라고 물어 최신 이름으로 바꿉니다

6. 성격을 바꿔 보기

코드는 그대로 두고 성격 문장만 바꾸면 앱의 쓸모가 달라집니다. 같은 질문을 던져 놓고 문장만 바꿔 보면 차이가 바로 보입니다.

💡 성격 문장 예시 — 그대로 넣어 보세요
  • 되물어보는 조교 — "너는 정답을 바로 알려 주지 않는 조교야. 먼저 힌트를 하나 주고 되물어봐. 학생이 스스로 답을 말하면 그때 확인해 줘"
  • 세 문장 요약가 — "너는 무엇을 물어도 세 문장 이내로 답해. 예시를 하나만 덧붙여"
  • 영어 회화 상대 — "너는 영어 회화 상대야. 영어로 먼저 답하고, 바로 아래에 한국어 뜻을 한 줄 달아 줘"
  • 어느 문장이든 끝에 "반드시 순수 한국어로만 답해" 같은 규칙을 덧붙이면 답이 훨씬 안정됩니다
③ 프롬프트 개선
좋아. 여기서 이어서 고쳐줘.
- 사이드바에 '말투 고르기'를 넣어줘.
  친절한 선생님 / 시크한 전문가 / 되물어보는 조교 세 가지로.
  고른 말투가 진행 중인 대화에도 다음 답부터 바로 적용되게 해줘.
- 사이드바에 성격 문장을 직접 고쳐 쓸 수 있는 칸도 넣어줘.
- '되물어보는 조교'는 정답을 바로 알려 주지 않고 힌트를 하나 준 뒤 되묻다가,
  학생이 스스로 답을 말하면 그때 확인해 주는 성격이야.
- 사이드바에 '대화 지우기' 버튼을 넣어서 쌓인 대화 기록을 비울 수 있게 해줘.
🧯 프롬프트가 어긋났다면 — 완성 코드 복붙 (말투 고르기·성격 고치기·대화 지우기 포함)

아래 코드를 app.py에 통째로 붙여넣고 커밋하면 같은 결과가 나옵니다. 금고에 SOLAR_API_KEY만 들어 있으면 됩니다.

app.py 전체 (그대로 복사)
import streamlit as st
from openai import OpenAI

st.set_page_config(page_title="AI 정보 선생님", page_icon="🤖")
st.title("🤖 AI 정보 선생님")

# 비밀 금고(secrets)에서 API 키를 꺼내 접속 준비
client = OpenAI(
    api_key=st.secrets["SOLAR_API_KEY"],
    base_url="https://api.upstage.ai/v1",
)

# 말투마다 다른 성격 문장을 미리 준비
TONES = {
    "친절한 선생님": "너는 중고등학생에게 설명하는 친절한 정보 선생님이야. 어려운 말은 쉬운 말로 바꿔 주고, 반드시 순수 한국어로만 답해",
    "시크한 전문가": "너는 군더더기 없이 핵심만 말하는 데이터 전문가야. 답은 세 문장 이내로, 반드시 순수 한국어로만 답해",
    "되물어보는 조교": "너는 정답을 바로 알려 주지 않는 조교야. 먼저 힌트를 하나 주고 되물어봐. 학생이 스스로 답을 말하면 그때 확인해 줘. 반드시 순수 한국어로만 답해",
}

tone = st.sidebar.radio("말투 고르기", list(TONES))
persona = st.sidebar.text_area("성격 문장 직접 고치기", TONES[tone], height=140)

if st.sidebar.button("대화 지우기"):
    st.session_state.messages = []
    st.rerun()

if "messages" not in st.session_state:
    st.session_state.messages = []

# 지금까지의 대화를 말풍선으로 다시 그리기
for msg in st.session_state.messages:
    with st.chat_message(msg["role"]):
        st.markdown(msg["content"])

user_input = st.chat_input("궁금한 것을 물어보세요!")

if user_input:
    st.session_state.messages.append({"role": "user", "content": user_input})
    with st.chat_message("user"):
        st.markdown(user_input)

    # 성격 문장을 맨 앞에 붙여 보내면 진행 중인 대화에도 다음 답부터 반영된다
    payload = [{"role": "system", "content": persona}] + st.session_state.messages

    with st.chat_message("assistant"):
        try:
            stream = client.chat.completions.create(
                model="solar-open2",
                messages=payload,
                reasoning_effort="none",
                stream=True,
            )
            answer = st.write_stream(
                chunk.choices[0].delta.content or ""
                for chunk in stream if chunk.choices
            )
            st.session_state.messages.append({"role": "assistant", "content": answer})
        except Exception:
            st.error("응답을 받지 못했습니다. 잠시 후 다시 보내 주세요.")
