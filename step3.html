A-1. 나이스 인증키 발급 (5분)

  • 나이스 교육정보 개방 포털 → open.neis.go.kr
  1. 1 · 로그인
    오른쪽 위 로그인 → 소셜 계정 중 하나로 (구글 · 카카오 · 네이버 · 페이스북). 별도 회원가입 절차는 없습니다
  2. 2 · 인증키 신청
    상단 활용가이드 → 인증키 신청 (또는 마이페이지 → 인증키 발급)
  3. 3 · 신청서 작성
    활용 목적에 “교사 연수 실습용 급식·학사일정 조회 앱” 정도로 적고 신청
  4. 4 · 키 복사
    마이페이지 → 인증키 발급에서 발급된 키를 복사 → Streamlit Cloud 금고에 NEIS_KEY로 붙여넣기
💡 화면 구성은 조금씩 바뀔 수 있어요
  • 메뉴 이름이 위와 다르면 “인증키”가 들어간 항목을 찾으세요. 그래도 안 보이면 AI에게 “나이스 교육정보 개방 포털에서 인증키 신청 메뉴가 어디야?”라고 물어보기
  • 발급이 늦어지면 기다리지 말고 카드 B로 옮기세요. 키를 다루는 연습은 똑같이 됩니다

A-2. 우리 학교 코드 찾기

  • 나이스는 학교를 이름이 아니라 코드 두 개로 찾습니다 — 시도교육청코드(ATPT_OFCDC_SC_CODE) · 표준학교코드(SD_SCHUL_CODE)
  • 코드는 학교정보 창구(schoolInfo)가 이름으로 찾아 줍니다. 아래 주소의 학교 이름만 우리 학교로 바꿔 브라우저 주소창에 넣어 보세요
브라우저 주소창에 넣어 보기 (4단계 · 응답 확인)
https://open.neis.go.kr/hub/schoolInfo?Type=json&pSize=5&SCHUL_NM=당곡고등학교
  • JSON 안에 ATPT_OFCDC_SC_CODE(예: B10)와 SD_SCHUL_CODE(예: 7010073)가 보이면 성공
  • 앱에서는 이 조회를 코드가 대신합니다. 선생님은 학교 이름만 입력하면 돼요. 지금 한 번 보는 이유는 어떤 이름의 값이 오는지 확인하기 위해서입니다
  • 같은 이름의 학교가 전국에 여럿일 수 있어서, 앱에는 고르는 목록을 둡니다

A-3. 키 없이 부르면 걸리는 제약

⚠️ 인증키 없는 호출은 날짜 오름차순 5건만 옵니다
  • 한 번에 몇 건을 달라는 조건(pSize)을 100으로 줘도 5건에서 잘립니다. 실제로 확인한 값 — 3월~7월 급식을 요청하면 응답 머리에 총 82건이라고 적혀 오는데 실제로 온 건 3월 4일~3월 10일 5건이었습니다
  • 그래서 조회 기간을 넓게 잡을수록 가장 오래된 5건이 오고, “오늘 급식”이 3월 메뉴로 뜹니다
  • 연수에서는 인증키를 발급받아 이 제약을 피합니다. 집에서 키 없이 시도하면 이 현상을 반드시 만나요
  • 해법은 기간을 7일씩 끊어 한 주씩 뒤로 거슬러 찾는 것입니다. 7일 창에는 등교일이 많아야 5일이라 5건 한도에 걸리지 않아요. 아래 ② 코드가 이 방식이라 키가 있든 없든 같은 답이 나옵니다
  • 학사일정도 5건 한도가 같습니다. 다만 “앞으로 한 달”을 물으면 오름차순 5건이 곧 가장 가까운 일정 5건이라 키가 없어도 쓸 만하게 나옵니다

A-4. 만들기

① 샘플 프롬프트
스트림릿으로 우리 학교 급식·학사일정 앱 하나(app.py)를 만들어줘. 스트림릿 클라우드에 올릴 거야.

- 나이스 교육정보 개방 포털의 오픈 API를 쓸 거야. 기본 주소는 https://open.neis.go.kr/hub 이고,
  학교정보는 schoolInfo, 급식은 mealServiceDietInfo, 학사일정은 SchoolSchedule 이야.
  응답은 JSON으로 받게 Type을 json으로 보내줘.
- 인증키는 코드에 쓰지 말고, 비밀 금고(secrets)의 NEIS_KEY에서 불러와.
  나이스는 인증키를 KEY라는 이름으로 요청에 붙여야 해.
- 화면 맨 위에 학교 이름 입력칸을 두고, 그 이름으로 학교를 찾아줘.
  같은 이름의 학교가 여럿이면 고를 수 있게(드롭다운) 해주고,
  고른 학교의 시도교육청코드(ATPT_OFCDC_SC_CODE)와 표준학교코드(SD_SCHUL_CODE)를 작게 보여줘.
- 급식은 조식·중식·석식을 고를 수 있게 하고, 가장 최근 급식 한 끼를 보여줘.
- 중요: 급식 조회 기간은 반드시 7일 창으로 끊어서 요청하고,
  급식이 나올 때까지 한 주씩 뒤로 거슬러 최대 8주까지 찾아줘.
  긴 기간을 한 번에 요청하면 안 돼. 응답이 날짜 오름차순 5건으로 잘려서
  가장 오래된 급식이 오고 '가장 최근 급식'이 어긋나거든.
- 메뉴는 DDISH_NM 값 안에 줄바꿈 표시로 붙어 있어. 한 줄씩 나누고,
  괄호 안 알레르기 번호는 지워서 목록으로 보여줘. 칼로리(CAL_INFO)도 날짜 옆에 같이.
- 학사일정은 오늘부터 앞으로 30일까지 조회해서 날짜와 행사 이름(EVENT_NM)을 목록으로 보여줘.
  학년별로 같은 행사가 여러 줄 올 수 있으니 같은 줄은 한 번만 보여줘.
- 같은 요청을 반복하지 않게 조회 결과는 캐시에 잠깐 담아 둬.
- 학교를 못 찾거나 급식 기록이 없으면 에러 화면 대신 한국어 안내 문구를 보여줘.
- 필요한 라이브러리 목록(requirements.txt)도 같이 줘. 버전 숫자 없이 이름만,
  스트림릿·판다스·넘파이는 기본 설치라 빼고. 이 앱은 requests 하나면 돼.
- 초보자용 한국어 주석을 달아. app.py 전체 코드를 한 번에 줘.
  • 아래는 받게 될 코드의 모습 예시입니다. 함수 이름이나 배치가 달라도 화면이 제대로 뜨면 성공이에요
② AI가 준 코드 예시 (app.py)
import datetime
import re

import requests
import streamlit as st

BASE = "https://open.neis.go.kr/hub"

st.set_page_config(page_title="우리 학교 급식·학사일정", page_icon="🍚")
st.title("🍚 우리 학교 급식·학사일정")

# 비밀 금고(secrets)에 넣어 둔 나이스 인증키 불러오기
KEY = st.secrets["NEIS_KEY"]


def call(path, extra):
    """나이스 오픈 API를 부르고 결과 목록을 돌려주기. 결과가 없으면 빈 목록"""
    params = {"KEY": KEY, "Type": "json", "pSize": 100}
    params.update(extra)
    data = requests.get(f"{BASE}/{path}", params=params, timeout=10).json()
    if path not in data:
        return []
    return data[path][1]["row"]


@st.cache_data(ttl=3600)
def find_schools(name):
    """학교 이름으로 후보 찾기 (같은 이름의 학교가 여러 곳일 수 있음)"""
    return call("schoolInfo", {"SCHUL_NM": name})


@st.cache_data(ttl=1800)
def latest_meal(atpt, code, meal_code):
    """7일 창을 한 주씩 거슬러 올라가며 가장 최근 급식 한 건 찾기 (최대 8주)"""
    today = datetime.date.today()
    for week in range(8):
        end = today - datetime.timedelta(days=7 * week)
        start = end - datetime.timedelta(days=6)
        rows = call("mealServiceDietInfo", {
            "ATPT_OFCDC_SC_CODE": atpt,
            "SD_SCHUL_CODE": code,
            "MMEAL_SC_CODE": meal_code,
            "MLSV_FROM_YMD": start.strftime("%Y%m%d"),
            "MLSV_TO_YMD": end.strftime("%Y%m%d"),
        })
        if rows:
            return max(rows, key=lambda r: r["MLSV_YMD"])
    return None


@st.cache_data(ttl=3600)
def coming_schedule(atpt, code, days=30):
    """오늘부터 앞으로 며칠간의 학사일정"""
    today = datetime.date.today()
    return call("SchoolSchedule", {
        "ATPT_OFCDC_SC_CODE": atpt,
        "SD_SCHUL_CODE": code,
        "AA_FROM_YMD": today.strftime("%Y%m%d"),
        "AA_TO_YMD": (today + datetime.timedelta(days=days)).strftime("%Y%m%d"),
    })


def clean_dishes(text):
    """메뉴를 줄 단위로 나누고 괄호 안 알레르기 번호를 지우기"""
    dishes = []
    for d in text.split("<br/>"):
        d = re.sub(r"\s*\([0-9.\s]+\)", "", d).strip()
        if d:
            dishes.append(d)
    return dishes


name = st.text_input("학교 이름", "당곡고등학교")
schools = find_schools(name) if name.strip() else []

if not schools:
    st.info("학교 이름을 정확히 넣어 주세요. 예: 당곡고등학교")
    st.stop()

labels = [f'{s["SCHUL_NM"]} · {s["ATPT_OFCDC_SC_NM"]}' for s in schools]
picked = schools[labels.index(st.selectbox("학교 고르기", labels))]
st.caption(
    f'시도교육청코드 {picked["ATPT_OFCDC_SC_CODE"]} · '
    f'표준학교코드 {picked["SD_SCHUL_CODE"]}'
)

meal_names = {"조식": "1", "중식": "2", "석식": "3"}
meal_label = st.radio("끼니", list(meal_names), index=1, horizontal=True)

st.subheader("🍚 가장 최근 급식")
meal = latest_meal(picked["ATPT_OFCDC_SC_CODE"], picked["SD_SCHUL_CODE"], meal_names[meal_label])
if meal is None:
    st.warning("최근 8주 안에 급식 기록이 없어요. 방학이나 시험 기간일 수 있어요.")
else:
    ymd = meal["MLSV_YMD"]
    st.write(f'**{int(ymd[4:6])}월 {int(ymd[6:8])}일 {meal_label}** · {meal["CAL_INFO"]}')
    for dish in clean_dishes(meal["DDISH_NM"]):
        st.write("- " + dish)

st.subheader("📅 앞으로 한 달 학사일정")
events = coming_schedule(picked["ATPT_OFCDC_SC_CODE"], picked["SD_SCHUL_CODE"])
if not events:
    st.info("앞으로 한 달 안에 등록된 일정이 없어요.")
else:
    seen = set()
    for e in events:
        line = f'{e["AA_YMD"][4:6]}/{e["AA_YMD"][6:8]}  {e["EVENT_NM"]}'
        if line not in seen:
            seen.add(line)
            st.write("- " + line)

B-2. 만들기

  • KOBIS·나이스 같은 데이터 API는 물어보면 정해진 답이 옵니다. AI API는 매번 새로 생성한 답이 와요
  • 창구가 달라도 순서는 같습니다 — 주소 · 열쇠 · 요청 · 응답
  • 챗봇의 부품은 셋 — 입력창 · 말풍선 · 대화 기록 기억. 세 번째가 없으면 매번 처음 만난 사람처럼 답합니다
① 샘플 프롬프트
스트림릿으로 AI 채팅앱 하나(app.py)를 만들어줘. 스트림릿 클라우드에 올릴 거야.

- Solar API(모델 solar-open2, 접속 주소 https://api.upstage.ai/v1)를
  openai 라이브러리로 사용해.
- API 키는 코드에 쓰지 말고, 비밀 금고(secrets)의 SOLAR_API_KEY에서 불러와.
- 모델 이름은 'solar-open2'를 글자 그대로 써줘. 다른 이름으로 바꾸지 마.
- 답이 빨리 나오도록 추론(생각) 기능은 꺼줘.
  온도를 낮추는 게 아니라, 추론 강도를 '없음'으로 주는 방식이야.
- 채팅 입력창으로 메시지를 보내면, AI의 답이 말풍선으로 이어지게 해줘.
- 답변은 스트리밍으로 받아서, 글자가 실시간으로 흘러나오게 보여줘.
- 대화 기록을 기억해서, 이전에 나눈 이야기를 이어서 답하게 해줘.
- 시스템 프롬프트로 '너는 중고등학생에게 설명하는 친절한 정보 선생님이야.
  어려운 말은 쉬운 말로 바꿔 주고, 반드시 순수 한국어로만 답해'라는 성격을 줘.
- 요청이 실패하면 에러 화면을 그대로 보여주지 말고,
  한국어로 친절한 안내 문구를 보여줘.
- 필요한 라이브러리 목록(requirements.txt)도 같이 줘. 버전 숫자 없이 이름만,
  스트림릿·판다스·넘파이는 기본 설치라 빼고. 이 앱은 openai 하나면 돼.
- 초보자용 한국어 주석을 달아. app.py 전체 코드를 한 번에 줘.
  • 아래는 받게 될 코드의 모습 예시입니다. 형태가 조금 달라도 대화가 되면 성공이에요
② AI가 준 코드 예시 (app.py)
import streamlit as st
from openai import OpenAI

# 페이지 기본 설정
st.set_page_config(page_title="AI 정보 선생님", page_icon="🤖")
st.title("🤖 AI 정보 선생님")

# 비밀 금고(secrets)에서 API 키를 안전하게 불러오기
client = OpenAI(
    api_key=st.secrets["SOLAR_API_KEY"],
    base_url="https://api.upstage.ai/v1",
)

# 시스템 프롬프트 (AI의 성격 설정)
SYSTEM_PROMPT = (
    "너는 중고등학생에게 설명하는 친절한 정보 선생님이야. "
    "어려운 말은 쉬운 말로 바꿔 주고, 반드시 순수 한국어로만 답해"
)

# 세션에 대화 기록이 없으면 처음 한 번만 초기화
if "messages" not in st.session_state:
    st.session_state.messages = [{"role": "system", "content": SYSTEM_PROMPT}]

# 이전 대화를 말풍선으로 다시 그리기 (system 메시지는 숨김)
for msg in st.session_state.messages:
    if msg["role"] != "system":
        with st.chat_message(msg["role"]):
            st.markdown(msg["content"])

# 채팅 입력창
user_input = st.chat_input("궁금한 것을 물어보세요!")

if user_input:
    # 사용자 메시지를 기록하고 화면에 표시
    st.session_state.messages.append({"role": "user", "content": user_input})
    with st.chat_message("user"):
        st.markdown(user_input)

    # AI 답변 받아오기 (실패하면 에러 화면 대신 안내 문구)
    with st.chat_message("assistant"):
        try:
            stream = client.chat.completions.create(
                model="solar-open2",                 # 모델 이름은 그대로 유지
                messages=st.session_state.messages,  # 이전 대화 전체를 함께 보내기
                reasoning_effort="none",             # 추론 끄기 -> 바로 답변 시작
                stream=True,                         # 스트리밍 -> 글자가 실시간으로 흐름
            )
            answer = st.write_stream(
                chunk.choices[0].delta.content or ""
                for chunk in stream if chunk.choices
            )
            # AI 답변도 기록에 저장 (다음 질문에 이어서 사용)
            st.session_state.messages.append({"role": "assistant", "content": answer})
        except Exception:
            st.error("응답을 받지 못했어요 😢 잠시 후 다시 보내 주세요.")

✔️ 여기까지 성공 확인
  • 인사를 건네서 AI가 한국어로 답하면 성공. 글자가 흘러나오면 스트리밍까지 성공
  • 이름을 알려 준 뒤 “내 이름 뭐라고 했지?”라고 물어 기억하면 대화 기록까지 성공
  • 답이 한참 안 오면 → ①의 “추론(생각) 기능은 꺼줘” 두 줄이 빠졌는지 확인하고 다시 주문. 추론이 켜지면 수십 초 생각부터 합니다
  • 기다리는 동안 전송 연타 금지 (요청 과다 오류로 이어집니다)
③ 프롬프트 개선
좋아! 여기서 이어서 고쳐줘.
- 사이드바에 '말투 고르기'를 넣어줘(친절한 선생님 / 시크한 전문가 / 귀여운 친구).
  고른 말투가 시스템 프롬프트에 반영되고, 진행 중인 대화에도 다음 답부터 바로 적용되게 해줘.
- 사이드바에 '대화 지우기' 버튼을 넣어서 쌓인 대화 기록을 비울 수 있게 해줘.
- 학생이 답을 그대로 베끼지 못하게, 정답을 바로 말하지 말고
  힌트를 한 번 준 뒤 다시 물어보는 성격도 골라 쓸 수 있게 해줘.
