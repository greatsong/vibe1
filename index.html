데이터 바이브 코딩

실제 데이터로 앱을 만들어 배포하는 데이터 분석 프로젝트 4시간입니다.

🎯 오늘 만드는 것
  • 인구·고령화 지도 앱 — 처음으로 배포해 내 앱 주소를 얻습니다
  • 박스오피스 앱 — API 키를 발급받아 넣고 다시 배포합니다
  • 나만의 AI 채팅앱 — AI의 성격을 바꿔 가며 대화 앱을 만듭니다
  • 합친 사이트 하나 — 앞서 만든 앱을 한 주소에 모아 수업 도구 모음으로 만듭니다

📍 시작하기 전에

인트로 · 0~20분
🗺️ 우리 학교를 지도에
휴대폰으로 열어 학교를 검색하세요. 앞 화면 지도에 바로 나타납니다
준비물
🔑 계정 3개
깃허브 · 스트림릿 클라우드 · AI 서비스 세 계정을 시작 전에 로그인해 두세요

🧭 오늘 연수 흐름

STEP 1 · 20~80분
첫 배포
인구·고령화 지도 앱을 만들어 깃허브에 올리고, 스트림릿으로 배포해 내 주소를 얻습니다
STEP 2 · 90~130분
키 다루기
박스오피스 API 키를 코드 밖에 두는 법을 익히고, 고치면 바로 반영되는 배포를 확인합니다
STEP 3 · 130~165분
나만의 AI 채팅앱
STEP 2에서 익힌 키·금고 순서를 처음 보는 API에 다시 적용합니다
STEP 4 · 175~210분
합치기
여러 앱을 한 주소 안에 모읍니다. 내 수업 도구 모음이 됩니다
심화 자료
더 해 보고 싶을 때
데이터가 쌓이는 앱(DB), 오늘 다루지 않은 소재, 자동화를 다룹니다
참고
용어 사전
오늘 나오는 낱말을 한 줄씩 모았습니다
작품
🖼️ 작품 갤러리
만든 앱의 주소를 올리고 다른 선생님의 작품을 봅니다
🔑 API 키는 코드에 적지 않습니다

STEP 2부터 API 키를 씁니다. 키를 코드에 적어 깃허브에 올리면 그 순간 공개됩니다. 스트림릿의 비밀 금고(secrets)에 넣는 방법을 STEP 2에서 다룹니다.

💡 AI 응답이 교재와 달라도 괜찮습니다

같은 프롬프트라도 AI마다, 실행할 때마다 코드가 조금씩 다르게 나옵니다. 각 단계에 실행 검증을 마친 완성 코드를 접어서 넣어 두었으니, 막히면 그것을 쓰고 다음으로 넘어가면 됩니다.
