STEP 4 · 175~210분

앱 세 개를 한 주소로 합치기

🎯 이 35분에 만드는 것
  • 앱 세 개가 든 사이트 하나 — 고령화 지도 · 박스오피스 · AI 채팅을 왼쪽 메뉴에서 골라 씁니다
  • 주소는 STEP 1에서 받은 ~.streamlit.app 그대로, 저장소도 my-vibe-app 그대로입니다

지금까지는 main.py 하나를 계속 덮어썼습니다. 그래서 저장소에는 STEP 3에서 만든 앱만 남아 있습니다. 이번 시간에는 앱들을 나란히 두고 왼쪽 메뉴에서 고르게 만듭니다. 스트림릿이 폴더 하나로 이 구조를 지원합니다.

1. pages/ 폴더 규칙

앱 파일 옆에 pages라는 폴더가 있으면, 스트림릿은 그 안의 .py 파일을 각각 한 페이지로 읽고 왼쪽에 메뉴를 만들어 줍니다. 설정 파일도, 메뉴를 만드는 코드도 없습니다.

  • 폴더 이름은 pages 하나로 고정. 다른 이름은 인식하지 않습니다
  • 폴더 안의 .py 파일만 페이지가 됩니다. 하위 폴더와 다른 확장자는 무시됩니다
  • 앱 파일(main.py)은 그대로 첫 화면이 되고 메뉴 맨 위에 놓입니다

파일 이름이 곧 메뉴 이름입니다

이름 앞의 숫자와 밑줄을 떼고, 남은 밑줄을 공백으로 바꾼 것이 메뉴에 나옵니다.

파일 이름메뉴에 보이는 이름비고
1_고령화_지도.py고령화 지도앞 숫자는 떨어지고 밑줄은 공백이 됨
2_박스오피스.py박스오피스
3_AI_채팅.pyAI 채팅
지도.py지도숫자를 안 붙이면 번호 붙은 파일들 뒤로 감
  • 앞의 숫자는 메뉴 순서를 정합니다. 숫자를 붙인 파일이 먼저 나오고, 숫자끼리는 크기순입니다(03과 3은 같게 봅니다)
  • 오늘 만든 순서대로 보이게 하려면 1·2·3을 붙이세요
  • 한글 파일 이름도 됩니다. 깃허브 웹 화면에서 그대로 만들 수 있습니다
💡 이름 앞에 이모지를 넣으면 메뉴 아이콘이 됩니다
  • 1_🗺️_고령화_지도.py로 저장하면 메뉴에 🗺️ 고령화 지도로 나옵니다. 이모지는 아이콘으로 빠지고 이름에는 안 들어갑니다
  • 깃허브 파일 이름 칸에 이모지를 붙여넣기가 번거로우면 생략해도 됩니다. 아래 절차는 이모지 없이 갑니다

2. 저장소가 이렇게 바뀝니다

지금 (STEP 3 직후)
my-vibe-app/
├── main.py              ← STEP 3에서 만든 AI 채팅앱만 남아 있음
└── requirements.txt
이 시간이 끝나면
my-vibe-app/
├── main.py              ← 표지 (첫 화면)
├── requirements.txt    ← 저장소에 하나. 사이트 전체에 적용됨
└── pages/
    ├── 1_고령화_지도.py    ← STEP 1 코드 그대로
    ├── 2_박스오피스.py     ← STEP 2 코드 그대로
    └── 3_AI_채팅.py       ← STEP 3 코드 그대로
💡 앞 앱의 코드는 교재에서 복사하세요
  • main.py를 계속 덮어써 왔으니 저장소에는 마지막 앱만 남아 있습니다
  • STEP 1·STEP 2는 페이지 아래쪽 접힌 🧯 시간이 부족하거나 프롬프트가 어긋났다면 — 완성 코드 복붙 블록 안의 main.py 전체 (그대로 복사)에서 가져옵니다
  • STEP 3도 같은 🧯 완성 코드 복붙 블록의 main.py 전체 (그대로 복사)에서 가져옵니다. 말투 고르기·대화 지우기까지 포함된 버전입니다
  • 깃허브 커밋 기록에서 되살릴 수도 있지만, 지금은 복사가 빠릅니다
⚠️ 옮길 때 코드는 한 글자도 고치지 않습니다
  • 페이지 파일 하나하나가 독립된 스트림릿 앱입니다. import 줄부터 마지막 줄까지 통째로 들어갑니다
  • 페이지끼리 코드를 나눠 쓰거나 서로 부르지 않습니다. 각자 자기 데이터를 불러오고 자기 화면을 그립니다
  • st.set_page_config 줄은 파일마다 맨 위 첫 스트림릿 명령이어야 합니다. 복사한 코드에 이미 그렇게 들어 있습니다

3. 표지 만들기

첫 화면은 목차 노릇을 합니다. 데이터도 인증키도 쓰지 않는 화면이라 짧습니다. 이것도 주문해서 만듭니다.

① 샘플 프롬프트
스트림릿으로 만든 앱 세 개를 한 사이트에 모았어. 그 사이트의 첫 화면(main.py)을 만들어 줘.
왼쪽 메뉴는 pages 폴더에서 자동으로 생기니까, 표지 내용만 넣으면 돼.

- 제목은 "내 수업 도구 모음". 브라우저 탭 제목도 같게 하고 탭 아이콘은 공구상자 이모지로.
- 제목 아래에 안내 두 줄. 무엇을 모아 둔 사이트인지, 왼쪽 메뉴에서 고르라는 내용.
- 그 아래에 앱 소개를 세 칸으로 나란히. 칸마다 이모지 붙은 소제목, 한 줄 설명,
  그리고 그 페이지로 바로 가는 링크를 넣어 줘. 링크가 가리킬 파일은 이거야.
  - 고령화 지도 / 시군구별 고령화율을 색 진하기로 봅니다 / pages/1_고령화_지도.py
  - 박스오피스 / 어제 관객수 상위 10편을 표와 그래프로 봅니다 / pages/2_박스오피스.py
  - AI 채팅 / 궁금한 것을 물어보면 한국어로 답해 주는 채팅앱입니다 / pages/3_AI_채팅.py
- 맨 아래에 만든 사람과 연도를 작은 글씨로.
- 이 파일에서는 데이터도 인증키도 쓰지 마.
- 초보자용 한국어 주석을 달아서 main.py 전체 코드를 한 번에 줘.

돌아온 코드가 이런 모습이면 됩니다. 글자까지 같지 않아도 됩니다.

② AI가 준 코드 예시
import streamlit as st

# 화면 설정 (파일마다 맨 위, 첫 스트림릿 명령으로 둔다)
st.set_page_config(page_title="내 수업 도구 모음", page_icon="🧰", layout="wide")

st.title("🧰 내 수업 도구 모음")
st.write("2026 정보교사 자격연수에서 만든 앱을 한자리에 모았습니다.")
st.write("왼쪽 메뉴에서 보고 싶은 앱을 골라 주세요.")

st.divider()

# 앱 소개 세 칸
c1, c2, c3 = st.columns(3)

with c1:
    st.subheader("🗺️ 고령화 지도")
    st.write("시군구별 고령화율을 색 진하기로 봅니다.")
    st.page_link("pages/1_고령화_지도.py", label="열기", icon="➡️")

with c2:
    st.subheader("🎬 박스오피스")
    st.write("어제 관객수 상위 10편을 표와 그래프로 봅니다.")
    st.page_link("pages/2_박스오피스.py", label="열기", icon="➡️")

with c3:
    st.subheader("🤖 AI 채팅")
    st.write("궁금한 것을 물어보면 한국어로 답해 주는 채팅앱입니다.")
    st.page_link("pages/3_AI_채팅.py", label="열기", icon="➡️")

st.divider()
st.caption("만든 사람: ○○중학교 ○○○ · 2026")
⚠️ 링크에 적은 파일 이름과 실제 파일 이름이 같아야 합니다
  • st.page_link의 pages/… 경로는 실제 파일 이름과 한 글자도 다르면 안 됩니다. 다르면 그 줄에서 오류가 납니다
  • 페이지 파일 이름을 다르게 지으셨다면 세 줄의 경로도 같이 고쳐 주세요
  • 링크가 자꾸 어긋나면 그 세 줄을 지워도 됩니다. 왼쪽 메뉴는 그대로 있으니 이동에 문제가 없습니다

4. 합치는 절차

  1. 폴더와 첫 페이지를 한 번에
    깃허브 저장소 my-vibe-app → Add file → Create new file → 파일 이름 칸에 pages/1_고령화_지도.py 입력. 슬래시(/)를 치는 순간 pages 폴더가 만들어집니다 → STEP 1 완성 코드 붙여넣기 → 아래 Commit changes
  2. 나머지 두 페이지
    같은 방법으로 pages/2_박스오피스.py(STEP 2 코드), pages/3_AI_채팅.py(STEP 3 코드). 이미 pages 폴더가 생겼으니 폴더 안으로 들어가서 Add file을 눌러도 됩니다
  3. 첫 화면을 표지로 교체
    저장소 맨 위의 main.py → 연필 아이콘 → 기존 내용 전체 선택 후 삭제 → 위 표지 코드 붙여넣기 → Commit changes
  4. requirements.txt 확인
    저장소 루트의 파일 하나가 사이트 전체에 적용됩니다. 아래 세 줄이 다 들어 있는지 보고, 빠진 줄이 있으면 연필로 추가
  5. 앱 주소 새로고침
    내 ~.streamlit.app 주소로 가서 새로고침. 빌드에 1~3분 걸립니다. 화면 오른쪽 아래 Manage app을 열어 두면 진행 상황이 보입니다
requirements.txt (저장소 루트 · 세 줄)
plotly
requests
openai
⚠️ 메뉴에 페이지가 안 보일 때 볼 곳
  • 폴더 이름이 pages인지. Pages·page는 인식하지 않습니다
  • 폴더 위치가 저장소 맨 위, main.py와 나란한 자리인지
  • 확장자가 .py인지. 이름 칸에 .py를 안 적으면 확장자 없는 파일로 저장됩니다
  • 화면 구성은 조금씩 바뀔 수 있습니다. 버튼을 못 찾으면 화면을 캡처해서 AI에게 물어보세요

5. 금고는 사이트 하나에 하나입니다

페이지를 나눠도 금고는 그대로입니다. Settings → Secrets에 넣어 둔 값은 앱 단위로 저장되고, 어느 페이지에서 꺼내든 같은 값이 나옵니다. 페이지마다 다시 넣지 않습니다.

Settings → Secrets (지금 들어 있는 그대로 · 고칠 것 없음)
KOBIS_KEY = "STEP 2에서 넣은 키"
SOLAR_API_KEY = "STEP 3에서 받은 실습용 키"
  • 합치는 과정에서 금고를 건드릴 일이 없습니다. STEP 2·STEP 3에서 넣은 두 줄이 살아 있습니다
  • 박스오피스 페이지는 KOBIS_KEY를, AI 채팅 페이지는 SOLAR_API_KEY를 이 한 금고에서 각각 꺼내 씁니다
  • 페이지를 더 붙여 키가 늘면 이 화면에 줄을 더합니다
  • KeyError가 나는 페이지가 있으면 그 페이지가 쓰는 키 줄이 금고에 있는지, 이름이 한 글자도 다르지 않은지 확인
✔️ 여기까지 성공 확인
  • 왼쪽 메뉴에 네 줄이 보이면 됩니다 — main(표지) · 고령화 지도 · 박스오피스 · AI 채팅. pages 폴더에 넣은 파일은 세 개지만 표지가 맨 위에 한 줄 더 붙습니다
  • 메뉴 하나씩 눌러 세 페이지가 모두 오류 없이 뜨는지 확인. 지도가 그려지고, 박스오피스 표가 차고, AI가 답하면 끝입니다
  • 표지의 열기 링크를 눌러도 같은 페이지로 갑니다
  • 한 페이지에서 빨간 오류가 나도 왼쪽 메뉴와 나머지 페이지는 그대로 돌아갑니다. 오류 난 페이지 파일만 고치면 됩니다
🧮 메뉴 첫 줄이 main으로 나옵니다
  • 첫 화면의 메뉴 이름은 파일 이름에서 옵니다. 파일이 main.py라서 main으로 나옵니다
  • 코드 안의 탭 제목(page_title)을 바꿔도 이 메뉴 이름은 안 바뀝니다
  • 첫 화면 파일 이름은 앱을 배포할 때 지정한 값이라 지금 바꾸면 배포가 끊깁니다. 오늘은 그대로 둡니다

표지를 더 손보고 싶으면 대화로 이어서 고칩니다.

③ 프롬프트 개선
표지를 이어서 고쳐 줘.
- 앱 소개 세 칸을 테두리 있는 상자 안에 넣어서 카드처럼 보이게 해 줘.
- 표지 화면의 왼쪽 사이드바에 사이트 이름과 안내 한 줄을 넣어 줘.
- 맨 아래 작은 글씨에 내 학교와 이름을 넣고, 깃허브 저장소 주소를 링크로 걸어 줘.
- 화면이 좁은 휴대폰에서는 세 칸이 가로로 눌리지 말고 세로로 쌓이게 해 줘.
🧯 시간이 부족하거나 프롬프트가 어긋났다면 — 표지 완성 코드 복붙

아래 코드를 main.py에 통째로 붙여넣고 커밋하면 표지가 완성됩니다. 페이지 파일 세 개만 pages/에 들어가 있으면 됩니다.
