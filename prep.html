준비 · 연수 시작 전

계정 3개만 준비해 주세요

전부 무료이고 설치가 없습니다. 브라우저(크롬 권장)만 있으면 됩니다. 세 개 모두 5분 안에 끝납니다.

⏱ 연수 당일이 아니라 미리

4시간짜리 연수라 첫 60분이 가장 빡빡합니다. 현장에서 계정을 만들면 그 시간이 통째로 날아갑니다. 오시기 전에 로그인까지 확인해 주세요.

✅ 만들 계정 3개
  • ① 깃허브(GitHub) — 코드를 올려 두는 곳
  • ② 스트림릿 커뮤니티 클라우드 — 그 코드를 실제로 돌리는 곳 (깃허브 계정으로 로그인)
  • ③ AI 서비스 — 코드를 써 줄 도구 (클로드·챗지피티·제미나이 중 하나)
💡 셋의 관계

③에게 주문해서 코드를 받고, ①에 올리고, ②가 그걸 웹앱으로 켭니다. 오늘 네 번 반복할 흐름입니다.

① 깃허브 계정

이미 쓰고 계신 선생님은 건너뛰고 ②로 가세요. 수업에서 학생 과제를 받아 본 계정이 있다면 그대로 써도 됩니다.

  1. github.com 접속
    github.com → 우측 상단 Sign up
  2. 이메일 · 비밀번호 · Username 입력
    Username은 영어로. 앞으로 만들 앱 주소에 그대로 들어가니 짧고 깔끔하게 정해 주세요
  3. 이메일 인증
    메일함에 온 인증 코드를 입력합니다
  4. 완료
    무료(Free)가 기본입니다. 결제 정보를 넣는 화면은 없습니다
✔️ 확인

github.com/사용자이름이 열리면 됩니다. 사용자 이름은 꼭 기억해 두세요.

② 스트림릿 커뮤니티 클라우드

파이썬 코드를 웹앱으로 켜 주는 무료 서비스입니다. 가입이랄 게 따로 없고 깃허브로 로그인만 하면 됩니다.

  1. share.streamlit.io 접속
    share.streamlit.io
  2. Continue with GitHub
    반드시 ①에서 만든 같은 계정으로 로그인합니다
  3. 권한 허용(Authorize)
    저장소의 코드를 앱으로 켜려면 필요한 연결입니다
  4. 완료
    대시보드 화면이 뜨면 성공입니다

③ AI 서비스 (하나만)

이미 쓰시는 게 있으면 그걸 쓰면 됩니다. 교재의 프롬프트는 어느 AI에서도 재현되게 썼습니다.

서비스주소메모
클로드claude.ai강사 화면이 이 기준입니다
챗지피티chatgpt.com익숙하시면 이걸로
제미나이gemini.google.com구글 계정이면 바로 됩니다
💡 무료 요금제로도 됩니다

다만 무료 등급 모델은 긴 코드를 한 번에 못 주고 중간에 끊길 때가 있습니다. 그럴 땐 "이어서 줘"라고 하면 됩니다. 각 단계마다 완성 코드를 접어서 넣어 두었으니 막히면 그걸 쓰셔도 진도가 이어집니다.

🎒 체크리스트

  • 깃허브 가입 완료 — 내 사용자 이름 확인
  • 스트림릿 — 깃허브 계정으로 로그인 성공
  • AI 서비스 하나 로그인 성공
  • 세 계정의 이메일·비밀번호 메모
  • 노트북·충전기 — 대면 연수입니다. 화면이 클수록 편합니다
  • 브라우저는 크롬 권장
