# vibe1 — 정보교사 바이브 코딩 4시간

2026 정보교사 1급 정교사 자격연수용 웹 교재. 대면 4시간(240분) 과정.

- 교재: `https://greatsong.github.io/vibe1/`
- 설계문서: `../커리큘럼_설계문서_4시간.md`
- 기반: 서울대 평생교육원 15시간판 (`../web/`, 저장소 `snu-data-2026`)

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 허브 — 오늘의 흐름, 단계별 진입 |
| `map.html` | **인트로 · 참가자 폰** — 학교 검색 후 전송 |
| `board.html` | **인트로 · 앞 화면** — 실시간 전국 지도 |
| `Code.gs` | 인트로 백엔드 (Google Apps Script) |
| `prep.html` | 준비물 — 계정 3개 |
| `step1.html` | 20~80분 · 길 뚫기 (인구·고령화 지도, 첫 배포) |
| `step2.html` | 90~130분 · 키를 다루다 (KOBIS) |
| `step3.html` | 130~165분 · 나만의 AI 채팅앱 |
| `step4.html` | 175~210분 · 합치기 (멀티페이지) |
| `extra.html` | 심화 자료 (DB · 오늘 다루지 않은 것 · 자동화) |
| `glossary.html` | 용어 사전 |

교재는 **한 벌**이다. 독자가 교사이므로 호칭은 "선생님", 배지는 `선생님용`. 강사용 별책은 만들지 않았다.

15시간판의 `gate.js`·`release.js`(일차 순차 공개)는 가져오지 않았다. 하루 완결이라 잠글 이유가 없다.

## 연수 전 준비 (강사)

1. **계정 3개 사전 안내** — 연수 공지에 깃허브·스트림릿 클라우드·AI 서비스 가입을 넣는다. 현장에서 만들면 STEP 1이 무너진다.
2. **인트로 백엔드 배포** — 새 구글 스프레드시트를 만들고 `Code.gs`를 붙여넣어 웹 앱(액세스: 모든 사용자)으로 배포한 뒤, 나온 URL을 `map.html`과 `board.html`의 `API_URL`에 넣는다. 기존 워크샵 시트를 재사용하면 데이터가 섞인다.
3. **키 준비** — KOBIS는 전원 발급이 원칙이되 예비 키를 준비한다. AI 채팅앱 키는 강사가 제공한다.
4. **완성본 저장소** — 각 단계의 완성 코드를 공개 저장소에 올려 fallback 링크로 건다.
5. **데이터 점검** — 연수 전날 `../scripts/validate_data.py` 실행.
6. **와이파이** — 대면이라 동시 접속 대역을 확인한다. 스트림릿 빌드가 동시에 몰리면 느려진다.
