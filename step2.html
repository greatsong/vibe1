  • 키를 코드 밖에 두기 — 발급받은 인증키를 금고에 넣고, 코드는 이름으로 꺼내 씁니다
  • 파일 하나만 바꿔 커밋하기 — 저장소를 새로 만들지 않고 앱 내용만 교체합니다

1. KOBIS 키 발급

가입도 발급도 무료이고, 신청하면 바로 나옵니다. 심사 대기가 없습니다.

  1. 가입
    영화진흥위원회 오픈API kobis.or.kr/kobisopenapi 접속 → 오른쪽 위 로그인 → 로그인 화면 아래 회원가입
  2. 키 발급
    로그인한 상태에서 상단 키 발급/관리 → 다시 키 발급/관리 → 발급 신청 → 화면에 뜬 인증키 복사
  3. 문서는 열어만 두기
    상단 OPEN API → 제공서비스 → 일별 박스오피스. 지금 읽지 않아도 됩니다. 4절에서 통째로 씁니다
💡 발급이 지연되면 강사 예비 키로
  • 메일 인증이 안 오거나 가입에서 막히면 손 들어 주세요. 강사 예비 키를 드리고, 그 키로 그대로 진행하면 됩니다
  • 키 발급은 연수가 끝난 뒤 혼자 다시 해도 됩니다. 여기서 진도가 끊기는 쪽이 훨씬 손해입니다
⚠️ 화면 구성은 조금씩 바뀔 수 있습니다
  • 메뉴 이름이나 버튼 위치가 위 설명과 다르면, 화면을 캡처해서 AI에게 "여기서 API 키를 어디서 받나요"라고 물어보세요
  • 찾을 것은 하나입니다. 인증키(발급키)라는 낱말이 붙은 긴 문자열입니다

2. 앱을 만들기 전에, 주소창으로 한 번

KOBIS는 키를 주소에 붙여 보내는 방식이라 브라우저 주소창만으로 요청이 됩니다. 코드로 넘어가기 전에 키가 살아 있는지부터 확인합니다.

주소의 생김새 (직접 고칠 필요 없음 · 아래 상자 사용)
https://www.kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json?key=발급받은키&targetDt=20260728
🔗 주소 만들기 — 발급받은 키를 붙여넣기만 하세요
키를 붙여넣으면, 어제 날짜가 채워진 완성 주소가 여기 나타납니다
↗ 새 탭에서 열어 보기
키는 이 화면 안에서만 쓰이고 어디에도 저장·전송되지 않습니다 · 날짜는 한국 시간 기준 어제로 자동 계산 · 아래 금고(Secrets) 예시에도 이 키가 자동으로 채워집니다

화면 가득 글자 덩어리(JSON)가 뜨면 성공입니다. 한 줄로 뭉쳐 보여도 정상입니다. 응답은 이런 구조로 옵니다.

KOBIS 일별 박스오피스 응답 (필드 이름은 실제 그대로 · 값은 줄여서 표시)
{
  "boxOfficeResult": {
    "boxofficeType": "일별 박스오피스",
    "showRange": "20260728~20260728",
    "dailyBoxOfficeList": [
      {
        "rank": "1",
        "rankInten": "0",
        "movieNm": "영화 제목",
        "openDt": "2026-07-15",
        "audiCnt": "100148",
        "audiAcc": "3619226",
        "scrnCnt": "2108",
        "showCnt": "7258"
      },
      { "rank": "2", "movieNm": "다음 영화" }
    ]
  }
}
  • 겉상자 boxOfficeResult 안에 목록 상자 dailyBoxOfficeList가 있고, 그 안에 영화 한 편이 상자 하나로 들어 있습니다. 하루에 10편이 옵니다
  • rank 순위 · movieNm 영화명 · openDt 개봉일 · audiCnt 그날 관객수 · audiAcc 누적 관객수 · scrnCnt 스크린수 · showCnt 상영횟수 · rankInten 전날 대비 순위 증감
  • 덩어리 속에서 movieNm을 눈으로 찾아보세요. 어제 1위 영화가 그 안에 있습니다
⚠️ 숫자가 따옴표에 싸여 있습니다
  • "audiCnt": "100148". 관객수가 숫자가 아니라 글자로 옵니다
  • 글자인 채로는 정렬도 그래프도 엉킵니다. 숫자로 바꾸는 한 단계가 반드시 필요합니다. 4절 프롬프트에 이 조건을 적어 둔 이유입니다
📅 날짜 제약 두 가지
  • 날짜는 targetDt에 여덟 자리(yyyymmdd)로 넣습니다. 2026-07-28처럼 하이픈을 넣으면 안 됩니다
  • 조회 가능한 가장 늦은 날짜는 어제입니다. 오늘 날짜를 넣으면 오류가 아니라 빈 목록이 옵니다. 아직 집계 전이기 때문입니다
  • 과거 날짜는 넉넉히 열려 있습니다. 1년 전 날짜도 그날의 TOP 10이 그대로 옵니다
🔎 키가 틀리면 — 상태코드만 믿지 말 것
  • KOBIS는 키가 틀려도 상태코드는 200을 줍니다. 대신 응답에 faultInfo 상자가 옵니다
  • {"faultInfo": {"message": "유효하지않은 키값입니다.", "errorCode": "320010"}}가 보이면 키 복사가 잘못된 겁니다. 앞뒤 공백을 의심하세요
  • 수업에서 그대로 쓸 만한 사례입니다. 번호표(상태코드)와 서류 내용(응답)을 둘 다 확인해야 합니다

3. 키를 비밀 금고(secrets)에 넣기

방금 받은 키를 코드에 적지 않고 앱의 금고에 넣습니다. STEP 1에서 배포한 앱을 그대로 씁니다.

  1. 배포된 내 앱 열기
    STEP 1에서 받은 ~.streamlit.app 주소로 접속. 스트림릿 클라우드에 로그인된 상태여야 합니다
  2. 관리 화면 열기
    화면 오른쪽 아래 Manage app 클릭 → 로그 창이 열리면 오른쪽 위 ⋮(점 세 개) → Settings
  3. Secrets에 붙여넣기
    Secrets 항목 선택 → 아래 한 줄 붙여넣기 → Save
  4. 앱이 다시 뜨는지 확인
    저장하면 앱이 알아서 다시 시작합니다. 잠깐 기다렸다가 새로고침
Settings → Secrets (위 상자에 붙여넣은 키가 자동으로 채워집니다)
KOBIS_KEY = "발급받은_키_붙여넣기"
💡 Manage app이 안 보이면
  • share.streamlit.io에 로그인 → 앱 목록에서 내 앱 오른쪽 ⋮ → Settings로도 같은 화면에 갑니다
  • 화면 구성은 조금씩 바뀔 수 있습니다. 못 찾으면 화면을 캡처해 AI에게 물어보세요. 찾을 것은 Secrets라는 낱말 하나입니다
🔒 키를 코드에 적으면 안 되는 이유
  • API 키는 내 신분증입니다. 코드에 적어 GitHub 공개 저장소에 올리면 전 세계에 공개됩니다
  • GitHub에 올라온 키를 훑는 봇이 돌아다닙니다. 유료 API 키라면 요금이 남의 몫으로 나갑니다
  • 커밋 기록은 파일을 지워도 남습니다. 한 번 올라간 키는 삭제가 아니라 폐기하고 재발급이 답입니다
  • 클라우드 Secrets 화면에 넣으면 저장소에 파일 자체가 생기지 않으니 안전합니다

이름 세 곳이 한 글자도 다르면 안 됩니다

금고의 원리는 단순합니다. 키를 코드 밖에 두고, 코드는 이름으로 꺼내 씁니다. 그래서 이름 세 곳이 정확히 같아야 합니다.

어디에서어떻게 쓰나
① 금고 (Settings → Secrets)KOBIS_KEY = "발급받은 키"
② 코드st.secrets["KOBIS_KEY"]
③ 프롬프트"인증키는 비밀 금고(secrets)의 KOBIS_KEY에서 불러와"
  • 셋 중 하나라도 kobis_key·KOBIS-KEY처럼 다르면 앱이 금고에서 못 찾습니다 (KeyError)
  • ③처럼 이름을 콕 집어 말해야 AI도 같은 이름으로 코드를 씁니다. 프롬프트에 정확한 낱말이 필요한 이유입니다
💡 금고는 두 곳에 있습니다
  • 내 컴퓨터에서 실행할 때는 .streamlit/secrets.toml 파일, 클라우드에서는 앱 Settings → Secrets 화면
  • 적는 형식은 같습니다. 배포한 앱이 키를 못 찾는다면 클라우드 쪽 금고에 안 넣은 경우가 대부분입니다
  • 내 컴퓨터에서 파일을 쓴다면 .gitignore에 .streamlit/secrets.toml 한 줄을 꼭 넣어 주세요

4. 앱 바꿔 올리기

STEP 1 저장소 my-vibe-app의 app.py를 박스오피스 앱으로 통째로 교체합니다. 저장소도 앱 주소도 그대로입니다.

💡 덮어써도 앞 코드는 남아 있습니다
  • STEP 1의 지도 코드는 GitHub 커밋 기록에 그대로 있습니다. 언제든 되돌릴 수 있습니다
  • requirements.txt는 손대지 않아도 됩니다. STEP 1에서 이미 requests가 들어 있습니다

이번 프롬프트의 요령은 API 문서에서 복사한 부분을 끝에 통째로 붙이기입니다. 이렇게 하면 AI가 필드 이름을 지어내지 않습니다.

① 샘플 프롬프트
어제의 박스오피스를 보여 주는 스트림릿 앱 하나(app.py)를 만들어 줘. 스트림릿 클라우드에 올릴 거야.
아래에 공식 API 문서에서 복사한 내용을 붙였어.

- 인증키는 비밀 금고(secrets)의 KOBIS_KEY에서 불러와. 코드에는 절대 쓰지 마.
- 조회 날짜는 고정하지 말고 '어제'를 자동으로 계산해서 써. 오늘 건 아직 집계 전이거든.
  '어제'는 한국 시간 기준이야. 배포 서버 시계는 한국 시간이 아니야.
- 순위·영화명·개봉일·관객수·누적관객·스크린수를 표로 보여 줘.
- 1위 영화는 지표 카드 세 장으로 크게, 관객수 상위 5편은 막대그래프로.
- 요청이 실패하거나, 오류 상자가 오거나, 영화 목록이 비어서 올 때는
  빈 화면 대신 무엇을 확인해야 하는지 한국어로 안내해 줘.
- 필요한 라이브러리 목록(requirements.txt)도 같이 줘.
  버전 숫자 없이 이름만, 스트림릿·판다스·넘파이는 기본 설치라 빼고.
- 초보자용 한국어 주석을 달고 app.py 전체 코드를 한 번에 줘.

──── 아래는 KOBIS 공식 문서에서 복사한 부분 ────
요청 주소: https://www.kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json
요청변수: key(발급받은 인증키) · targetDt(조회 날짜, yyyymmdd 여덟 자리)
응답 구조: boxOfficeResult 안의 dailyBoxOfficeList 목록에 영화별로
  rank(순위) · rankInten(전날 대비 순위 증감) · movieNm(영화명) · openDt(개봉일) ·
  audiCnt(그날 관객수) · audiAcc(누적 관객수) · scrnCnt(스크린수) · showCnt(상영횟수)
  ※ 숫자 값이 전부 문자열로 온다.
  ※ 인증키가 틀려도 상태코드는 200이고, 대신 faultInfo 상자가 온다.

완성된 코드 한 덩어리가 돌아옵니다. 내 것과 글자까지 같지 않아도 됩니다. 이런 모습이면 성공입니다.

② AI가 준 코드 예시
import streamlit as st
import pandas as pd
import requests
from datetime import datetime, timedelta
from zoneinfo import ZoneInfo

st.set_page_config(page_title="박스오피스 대시보드", layout="wide")
st.title("🎬 어제의 박스오피스")

# 비밀 금고에서 인증키 꺼내기 (코드에는 키를 적지 않는다)
KOBIS_KEY = st.secrets["KOBIS_KEY"]

# 한국 시간 기준 어제 날짜를 여덟 자리로 (배포 서버 시계는 외국 기준일 수 있다)
yesterday = datetime.now(ZoneInfo("Asia/Seoul")) - timedelta(days=1)
target_dt = yesterday.strftime("%Y%m%d")
st.caption(f"조회 기준일(어제): {yesterday.strftime('%Y-%m-%d')}")

url = "https://www.kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json"
res = requests.get(url, params={"key": KOBIS_KEY, "targetDt": target_dt}, timeout=10)

if res.status_code != 200:
    st.error(f"요청이 실패했습니다 (상태코드: {res.status_code})")
    st.stop()

data = res.json()

# KOBIS는 키가 틀려도 상태코드 200을 준다. 대신 faultInfo 상자가 온다.
if "faultInfo" in data:
    st.error("인증키가 올바르지 않습니다. 금고(Secrets)의 KOBIS_KEY를 확인해 주세요.")
    st.stop()

box_list = data.get("boxOfficeResult", {}).get("dailyBoxOfficeList", [])
if not box_list:
    st.warning("그날 자료가 없습니다. 날짜를 하루 더 앞으로 옮겨 보세요.")
    st.stop()

df = pd.DataFrame(box_list)

# 글자로 온 숫자들을 진짜 숫자로 바꾸기
for col in ["rank", "audiCnt", "audiAcc", "scrnCnt", "showCnt"]:
    df[col] = pd.to_numeric(df[col])

# 1위 영화 지표 카드 세 장
top = df.sort_values("rank").iloc[0]
c1, c2, c3 = st.columns(3)
c1.metric("어제 1위", top["movieNm"])
c2.metric("어제 관객수", f"{top['audiCnt']:,}명")
c3.metric("누적 관객", f"{top['audiAcc']:,}명")

# 표를 한국어 열 이름으로 정리
table = df[["rank", "movieNm", "openDt", "audiCnt", "audiAcc", "scrnCnt"]].copy()
table.columns = ["순위", "영화명", "개봉일", "관객수", "누적관객", "스크린수"]
table = table.sort_values("순위").reset_index(drop=True)

st.subheader("📋 박스오피스 TOP 10")
st.dataframe(table)

st.subheader("📈 관객수 상위 5편")
top5 = table.sort_values("관객수", ascending=False).head(5)
st.bar_chart(top5.set_index("영화명")["관객수"])

  • 그 아래 표에 영화 10줄이 순위대로 있고, 맨 아래 막대그래프에 영화 5편이 그려져 있습니다
  • 주소는 STEP 1과 같은데 지도가 있던 자리에 영화 표가 있습니다. 저장소를 새로 만들지 않았습니다
  • KeyError: 'KOBIS_KEY'가 뜨면 3절 이름 표를 다시 보세요
  • 화면이 안 바뀌면 Manage app 로그 창에서 빌드가 아직 도는지 확인. 그래도 그대로면 로그 창 ⋮ 메뉴의 Reboot app
  • 막히면 화면의 에러 메시지를 통째로 복사해 AI에게 붙여넣으세요

6. 프롬프트 개선

화면이 떴으면 대화로 이어서 고칩니다. 새 창을 열지 말고 같은 대화에서 이어 말하는 게 중요합니다.

③ 프롬프트 개선
좋아, 여기서 이어서 고쳐 줘.
- 날짜를 어제로 고정하지 말고, 달력에서 골라 그날의 박스오피스를 볼 수 있게 해 줘.
  고를 수 있는 가장 늦은 날짜는 어제까지야. 오늘 건 아직 집계 전이니까.
- 고른 날짜에 영화 목록이 비어서 오면 "그날은 아직 집계 전입니다"라고 알려 줘.
- 문서를 보니 rankInten이라는 값이 전날 대비 순위 증감이래. 양수면 순위가 오른 것, 음수면 내린 것.
  표에서 오른 영화는 빨간 위 화살표, 내린 영화는 파란 아래 화살표를 붙여 줘.
- 누적관객이 100만 명을 넘은 영화는 영화명 옆에 트로피 이모지를 붙여 줘.
🧯 시간이 부족하거나 프롬프트가 어긋났다면 — 완성 코드 복붙

아래 코드를 app.py에 통째로 붙여넣고 커밋하면 같은 결과가 나옵니다. 금고에 KOBIS_KEY만 들어 있으면 됩니다. 먼저 진도를 맞추고, 프롬프트는 쉬는 시간에 다시 돌려 보셔도 좋습니다.

app.py 전체 (그대로 복사)
import streamlit as st
import pandas as pd
import requests
from datetime import datetime, timedelta
from zoneinfo import ZoneInfo

st.set_page_config(page_title="박스오피스 대시보드", layout="wide")
st.title("🎬 어제의 박스오피스")

KOBIS_KEY = st.secrets["KOBIS_KEY"]

yesterday = datetime.now(ZoneInfo("Asia/Seoul")) - timedelta(days=1)
target_dt = yesterday.strftime("%Y%m%d")
st.caption(f"조회 기준일(어제): {yesterday.strftime('%Y-%m-%d')}")

url = "https://www.kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json"
res = requests.get(url, params={"key": KOBIS_KEY, "targetDt": target_dt}, timeout=10)

if res.status_code != 200:
    st.error(f"요청이 실패했습니다 (상태코드: {res.status_code})")
    st.stop()

data = res.json()

if "faultInfo" in data:
    st.error("인증키가 올바르지 않습니다. 금고(Secrets)의 KOBIS_KEY를 확인해 주세요.")
    st.stop()

box_list = data.get("boxOfficeResult", {}).get("dailyBoxOfficeList", [])
if not box_list:
    st.warning("그날 자료가 없습니다. 날짜를 하루 더 앞으로 옮겨 보세요.")
    st.stop()

df = pd.DataFrame(box_list)

for col in ["rank", "audiCnt", "audiAcc", "scrnCnt", "showCnt"]:
    df[col] = pd.to_numeric(df[col])

top = df.sort_values("rank").iloc[0]
c1, c2, c3 = st.columns(3)
c1.metric("어제 1위", top["movieNm"])
c2.metric("어제 관객수", f"{top['audiCnt']:,}명")
c3.metric("누적 관객", f"{top['audiAcc']:,}명")

table = df[["rank", "movieNm", "openDt", "audiCnt", "audiAcc", "scrnCnt"]].copy()
table.columns = ["순위", "영화명", "개봉일", "관객수", "누적관객", "스크린수"]
table = table.sort_values("순위").reset_index(drop=True)

st.subheader("📋 박스오피스 TOP 10")
st.dataframe(table)

st.subheader("📈 관객수 상위 5편")
top5 = table.sort_values("관객수", ascending=False).head(5)
st.bar_chart(top5.set_index("영화명")["관객수"])

용어뜻
API 키(인증키)"이 서비스를 쓰는 사람"임을 증명하는 문자열. 신분증에 해당
비밀 금고(secrets)키를 코드 밖에 보관하는 자리. 코드는 이름으로 꺼내 씀
secrets.toml내 컴퓨터에서 쓰는 금고 파일. GitHub에 올리지 않도록 .gitignore에 넣어 둠
JSON라벨과 값의 짝으로 이루어진 데이터 양식. 상자 안에 상자를 넣을 수 있음
상태코드응답에 함께 오는 번호. 200 성공, 404 주소 오류, 429 요청 과다
faultInfoKOBIS가 실패를 알리는 상자. 상태코드는 200인데 내용은 오류
targetDtKOBIS에 조회 날짜를 넘기는 이름. 하이픈 없이 여덟 자리(yyyymmdd)
커밋(commit)"이 상태로 저장" 도장. GitHub에 커밋하면 클라우드가 앱을 다시 배포함
